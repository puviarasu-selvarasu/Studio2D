# Studio2D

Studio2D is a local-first AI-assisted animation production system.

Its long-term goal is to help a human creator produce episodic 2D animation
using a traditional hand-drawn/cel-inspired visual language together with
modern digital production techniques.

## Core stack

- Python
- Blender / Grease Pencil
- Ollama
- FFmpeg

## Engineering philosophy

Use proven existing technology before building custom technology.

Reuse before regeneration.

Templates before custom engines.

Sequential processing before parallel processing.

CPU-first development.

The human creator remains the final production authority.

## Current phase

Phase 0 - Foundation and environment verification.
