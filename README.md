# Studio2D

Studio2D is a local-first, CPU-first virtual anime production studio.

The project targets a Windows 11 laptop with modest hardware and uses
deterministic production systems before generative AI systems.

## Current development stage

Phase 0 - Visual and Technical Feasibility Laboratory.

Current checkpoint:

0A - Minimal Engineering Foundation

The immediate production objective is to prove one convincing
5-10 second cel-styled anime shot before building the larger production
architecture.

## Core tools

- Python
- Blender
- FFmpeg
- Ollama
- Git

## Development rule

Build only what the current proof requires.

Do not prematurely build agents, RAG, UI, full episode production,
crowd generation, voice, music, or other mature systems.
